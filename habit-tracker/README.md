# Habit Tracker (CLI)

Aplikasi sederhana untuk mencatat kebiasaan harian, melihat grafik ASCII progres 14 hari, dan ringkasan mingguan.

## Fitur
- Tambah / hapus kebiasaan
- Catat kebiasaan per tanggal
- Lihat ringkasan & ASCII calendar (14 hari terakhir)
- Laporan mingguan dibandingkan target

## Jalankan
python tracker.py
